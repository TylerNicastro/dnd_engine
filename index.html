D&D Engine

Build characters step by step, keep a sheet where every number explains itself, level up with hit dice, feats and spells, and create your own homebrew, from magic items to full classes and battle maps.

Download ZIP View on GitHub

A Java desktop app: download it and run it on your computer (Windows, macOS or Linux). How to run it

Features

Everything happens in one window. Click any stat, skill, item, feature, condition or language to see what it is, what it's used for, and where it comes from.

Character creation

A guided wizard for species and lineage, class, ability scores (point buy, rolling or custom), background, skills, languages, spells and starting equipment.

Clickable character sheet

Every value explains its math and its source. Track conditions, coins, equipment, hit dice and death saves right on the sheet.

Level up & multiclass

Roll or enter hit points, pick feats, ability score improvements and epic boons, multiclass, and choose new spells as you go.

Spells

A full 2024 spell registry with spell cards, slot tracking, Pact Magic, rituals and concentration, plus clickable conditions inside spell text.

Asset Library

Create, edit, duplicate and delete your own homebrew in 11 categories, then share it as a JSON pack.

Grid map editor

Build battle maps from scratch: walls, doors (open or closed), windows, five floor types, pan and zoom, undo, and clickable encounter pins.

Homebrew that plugs into the rules

Assets you create are merged into the game data as soon as you save them. A homebrew class shows up in the creation wizard and in level up; a homebrew weapon counts toward attacks and equipment choices; a homebrew condition becomes clickable everywhere it's mentioned.

  • Items · gear, consumables, wondrous, tools
  • Weapons · damage, properties, mastery
  • Armor · AC, DEX cap, STR, stealth
  • NPCs · full stat blocks
  • Maps · grid, walls, doors, pins
  • Conditions
  • Spells · levels 0 to 9
  • Backgrounds · skills, tools, origin feat
  • Species · size, speed, darkvision, traits
  • Classes · levels 1 to 20, spellcasting
  • Subclasses

Share homebrew packs

Export any mix of categories to a .json file and send it to your group. When you import a pack, you choose what happens to name clashes: keep both, replace, or skip. Pins on imported maps stay linked to imported NPCs.

Your own homebrew is saved in custom_assets.json next to the app.

// homebrew_pack.json (excerpt)
{
  "format": "dnd-engine-homebrew",
  "conditions": [
    { "name": "Bleeding",
      "description": "Lose 1d4 HP at the start of each turn." }
  ],
  "weapons": [
    { "name": "Stormglass Saber",
      "weaponCategory": "Martial", "weaponType": "Melee",
      "damageDice": "1d8", "damageType": "Lightning",
      "properties": ["Finesse", "Versatile"],
      "versatileDamage": "1d10", "mastery": "Vex" }
  ]
}

Get started

D&D Engine is a Java desktop app. You need a Java Development Kit (JDK) 11 or newer. Any recent build works, for example Eclipse Temurin.

  1. Download the ZIP and unzip it, or clone the repository.
  2. Open a terminal in the project folder (the one containing src and weapons.json).
  3. Compile, then run. Always run from the project folder: the app reads and writes its data files there.
Your data stays local. Characters are saved to characters.json and homebrew to custom_assets.json in the project folder. Back those files up to keep your work.
# get the code
git clone https://github.com/TylerNicastro/dnd_engine.git
cd dnd_engine
# compile and run (macOS, Linux, Git Bash)
javac -d bin src/*.java
java -cp bin App
# Windows PowerShell
javac -d bin (Get-ChildItem src\*.java).FullName
java -cp bin App
