    How D&D Engine works

    D&D Engine is a free, unofficial character builder and homebrew toolkit for Dungeons & Dragons using the 2024 rules (often called 5.5e). It runs in your browser or as a desktop app, and your data stays on your device.

    What is D&D Engine?

    It's a Java application that handles the bookkeeping of building and playing a character: ability scores, proficiencies, spells and spell slots, hit points, feats and equipment. It knows the 2024 rules for character creation and leveling, so it can offer the right choices at each step and explain where every number comes from.

    The same program runs in two places:

    • In your browser on the Main App page. It uses CheerpJ to run Java inside the page, so there's nothing to install.
    • On your computer as a desktop app for Windows, macOS or Linux. See Download.

    It's a fan project, not an official product. The rules text in it is short paraphrased summaries, not the full books. See the Fan Content Disclaimer.

    Features

    Character wizard

    Step by step: species, class, ability scores (point buy, rolled or custom), background, skills, languages, spells and starting equipment.

    Character sheet

    Stats, skills, spells and slots, equipment, coins and conditions. Click any value to see what it is and where it comes from.

    Level up

    Hit points, multiclassing, feats and epic boons, new spells and spell swaps, following the 2024 rules.

    Asset Library

    Browse every built-in spell, feat, class, species, background, condition and item, and create your own homebrew.

    Tags & filters

    Every asset is tagged by source. Turn a tag off to keep it out of character creation and level up.

    Maps & combat

    Grid maps with walls, doors and encounter pins. Place character and NPC tokens (custom shapes, colors or pictures, sized by creature size), then run combat with teams, initiative, turn order and movement range.

    How to use the app

    1. Launch it. On the Main App page, click Launch the app. The first launch downloads the Java runtime and can take a minute.
    2. Create a character. Choose Characters on the main menu, then add a new player character. The wizard walks through each step; the panel on the right explains every option, and you can jump back to any step from the progress bar.
    3. Use the sheet. Open a character to see their sheet. Click stats, skills, spells, items or conditions for details. Track hit points, spell slots, coins and conditions as you play.
    4. Level up. From the sheet, choose Level Up. Pick which class gains the level (or multiclass), then make the choices that level grants.
    5. Browse and build homebrew. Choose Assets on the main menu to open the Asset Library.

    Everything stays in one window: details, pickers and confirmations open as panels inside the app.

    Asset Library & homebrew

    The Asset Library lists every asset in one place: the built-in official content and anything you've created. The All tab shows everything together with category badges; the other tabs show one category each.

    • Search with the bar at the top of the library. It searches every category at once: names, rules text and tags.
    • Sort by name, by tag / source, or by level / category.
    • On the Spells tab, filter by school, spell level and class with the chips under the title.
    • Create homebrew with the + New button on any category tab: items, weapons, armor, spells, feats, species, backgrounds, classes, subclasses, conditions, NPCs and maps. Homebrew joins the same lists the wizard, level up and the sheet use.
    • Share homebrew with the library's Export JSON and Import JSON buttons, which save or load a homebrew pack.

    Tags & content filters

    Every asset has tags. Built-in content starts with OFFICIAL plus its sourcebook (CORE RULES, XANATHAR'S GUIDE, TASHA'S CAULDRON and so on). Homebrew starts with HOMEBREW. Spells also get automatic tags for their school, level and class lists.

    Use the tag button on any asset to add or remove tags, or create your own (for example Banned or Setting: Eberron). In the library, Tags & Filters lets you turn tags off for your campaign. Anything carrying a turned-off tag is hidden from the character wizard, level up, and the equipment and condition pickers. Characters keep anything they already have.

    Browser saving

    In the browser version, the app saves automatically as you go. Your characters, homebrew, tags and filters are stored in your browser's storage (IndexedDB) on this device only. Nothing is uploaded; there are no accounts and no server copy.

    That means your data is not there if you:

    • clear this site's data or your browser history,
    • use a private or incognito window, or
    • open the site in a different browser or on a different device.

    Browsers can also clear site storage on their own when a device runs low on space. Export a backup now and then.

    The desktop version saves to files next to the app instead: characters.json and custom_assets.json.

    JSON backups (Export / Import)

    Backups are made inside the app. On the app's main menu, click Backup & Restore (Export / Import JSON).

    • Export JSON saves one file containing every character and all your homebrew, including tags and content filters. In the browser it's downloaded like any other file; on the desktop it's saved in the app's folder.
    • Import JSON loads a file and asks you to confirm before changing anything. It accepts:
      • a full backup, which replaces all characters and homebrew;
      • a characters.json file, which replaces your characters and keeps your homebrew;
      • a homebrew pack, which adds its assets to your library (name clashes are kept and renamed).

    Backups are plain JSON, so they work in both versions. Export in the browser and import on the desktop, or the other way round, to move your data.

    FAQ

    Is it free?

    Yes. There are no ads, paywalls or paid features. The source code is on GitHub under the MIT License.

    Does it work on a phone?

    It runs, but it's designed for larger screens. A tablet or computer works best; on a phone, turn it sideways.

    Does it work offline?

    The browser version needs a connection to download the Java runtime. The desktop version works fully offline.

    Where are the full rules?

    D&D Engine only includes short summaries. For the complete rules, use the official books or the free System Reference Document from Wizards of the Coast.

    I found a bug or a rules mistake.

    Please open an issue on GitHub. Your Dungeon Master's ruling always wins in the meantime.
