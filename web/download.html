    Desktop version

    The desktop version is the same app as the browser version. It runs fully offline, starts faster, and saves your characters to files on your computer that you can back up like any other file.

    Download for Windows, macOS & Linux (.zip) Source on GitHub

    One download for every platform. The zip contains dnd_engine.jar (the app), its rules data files (spells.json, weapons.json), the README and the MIT license. It's rebuilt automatically from the latest code every time the project is updated.

    Requirements

    The app needs Java 11 or newer. If you don't have it, install a free Java runtime such as Eclipse Temurin (pick the latest LTS release for your system).

    To check whether Java is installed, open a terminal (Command Prompt on Windows) and run:

    java -version

    Any version number of 11 or higher is fine.

    Windows

    1. Download the zip above, right-click it and choose Extract All….
    2. Open the extracted dnd_engine folder and double-click dnd_engine.jar.
    3. If double-clicking opens the jar in another program, run it from Command Prompt instead: 
      cd %USERPROFILE%\Downloads\dnd_engine
java -jar dnd_engine.jar

    macOS

    1. Download the zip above and double-click it to extract the dnd_engine folder.
    2. Open Terminal and run: 
      cd ~/Downloads/dnd_engine
java -jar dnd_engine.jar
    3. Double-clicking dnd_engine.jar also works once Java is installed. The jar isn't signed by Apple, so the first time macOS may say it's from an unidentified developer. If so, right-click (or Control-click) the jar, choose Open, then confirm.

    Linux

    1. Install Java 11+ from your package manager (for example sudo apt install openjdk-17-jre on Debian or Ubuntu).
    2. Extract and run: 
      unzip dnd_engine-desktop.zip
cd dnd_engine
java -jar dnd_engine.jar

    Your data

    The desktop version saves to two files in the same folder as dnd_engine.jar:

    • characters.json: your characters
    • custom_assets.json: your homebrew, tags and content filters

    Keep these files when you update: extract a new download over the old folder, or copy the two files into the new one. Deleting the folder deletes your saves.

    Moving between the browser and the desktop: in either version, open Backup & Restore on the app's main menu and use Export JSON. In the other version, use Import JSON on the same screen. On the desktop, put the backup file in the app's folder first; the import screen lists the .json files it finds there. See JSON backups for details.

    Build from source

    The code is on GitHub under the MIT License. With a JDK (11 or newer) installed:

    git clone https://github.com/TylerNicastro/dnd_engine.git
cd dnd_engine
javac -encoding UTF-8 -d bin src/*.java
java -cp bin App

    To build the browser version and this download, run bash web/build.sh (or web\build.ps1 on Windows).
