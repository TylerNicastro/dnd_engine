    D&D Engine

    Build D&D 2024 characters, level them up, and create your own homebrew items, spells, classes and battle maps, all in your browser.

    Desktop version

    The first launch downloads a Java runtime, which can take a minute; later visits are faster. Your characters are saved only in this browser. Use Backup → Export JSON to keep a copy.

    Tip: the app is designed for larger screens. On a phone, turn it sideways or use a tablet or computer for the best experience. The search bar above works great on any screen.
